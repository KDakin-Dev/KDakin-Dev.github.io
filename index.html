Method

How I approach bugs and systems.

I prefer clear contracts, small verification loops, and direct reproduction paths before large rewrites.

Trace

Observe runtime state

Capture inputs, metrics, visual state, and the exact moment when behavior diverges.

Isolate

Separate ownership

Find which module owns state, rendering, input, or timing before changing behavior.

Verify

Test the contract

Use minimal checks, logs, and focused runs so fixes are measurable instead of cosmetic.

Clean

Remove legacy drift

Prefer one path, one source of truth, and no hidden compatibility branches after migration.
