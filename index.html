Architecture layer

What this site is demonstrating.

The background is not a video. It is a browser-side procedural simulation running on Canvas, connected to pointer input and scroll state.

01 / FIELD

Procedural background

Nodes move in a vector field, form temporary links, and react to the pointer. The page keeps the visual layer live without heavy media assets.

02 / INPUT

Real-time interaction

Mouse movement bends trajectories, clicks inject impulses, and scroll changes the energy profile of the system behind the content.

03 / LAYERS

HUD composition

Canvas, scanline overlay, vignette, sticky navigation, and glass panels are separated into clear visual layers with predictable z-index behavior.
