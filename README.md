# KDakin-Dev.github.io

Portfolio site with playable browser prototypes.

## Playable pages

- `index.html` - main portfolio page.
- `sail_game.html` - Sail & Fire playable canvas prototype.

## Sail & Fire controls

- W / S - raise or lower sail.
- A / D - rudder.
- Mouse - aim.
- Left mouse button or Space - fire.
- P - pause.

Use `sail_game.html?debug=1` to show debug vectors and counters.
